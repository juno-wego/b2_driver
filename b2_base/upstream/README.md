# Unitree SDK2 source boundary

`unitree_sdk2/` is the pinned, unmodified official Unitree SDK2 git submodule.
It provides `SportClient`, DDS channels, generated IDL headers, and its bundled
CycloneDDS libraries.

The sibling `../wego/` directory is this repository's ROS adapter code. Update
the submodule on a dedicated branch and
validate the driver before recording a new submodule commit.
